# ten Android画面リーダー（試用版0.4）

他アプリを見ながらtenアイコンを押し、OSの画面取得に同意すると、表示中の本文候補を端末内で認識し、同じアプリの上に定点リーダーを表示する。Android 8以降、compile/target SDK 36。現在のアプリ名は「ten 起動ボタン」。

## 使い方

1. APKをインストール／更新し、「画面のボタンを表示」から重ね表示を許可する。
2. 読みたいアプリを開き、tenアイコンを押す。OSの確認で対象アプリまたは画面の取得を許可する。
3. 本文候補を定点表示する。停止・再生・前後移動・読む位置・速度・意味／単語／一文字・文字サイズ・標準／明朝を選べる。
4. 誤った範囲は「範囲・文章・文字サイズを直す」で画像上を囲み直すか、全文へ戻して本文を修正する。原寸画像の再送信や再OCRは行わない。
5. 閉じる／通知の停止で読書を終了する。続きは元の画面を動かしてアイコンから取得し直す。

## 自動スクロール（任意・初期OFF）

アプリの「自動スクロールを設定」で用途の説明に同意し、Androidのユーザー補助設定で「ten 自動スクロール」を手動で有効にする。読みたいアプリに戻り、アイコンから新たなOS同意を受ける。自動時は全画面の共有を要求するが、対象windowと共有範囲を確認し、システムバーを除いた対象アプリ領域だけをOCRへ渡す。

読了ごとに、自分の読書欄を隠す→対象の下方向操作を1回→対応するscroll eventと安定待ち→新しいImageReaderで次画面取得→本文の重複を除去→続きを再生する。同じVirtualDisplayを使い、画面共有トークンを再利用して別のVirtualDisplayを作らない。API35以降で部分スクロール対応nodeは0.7画面を指定する。それ以外は対象アプリの既定の移動量になる。本文または原OCRで12書記素以上の前画面末尾と次画面先頭の一致を確認できない場合、自動再生・共有・操作を停止する。scrollableであっても連続読書できるとは限らない。

0.4では下方向の本文領域を優先・固定し、外側の横pagerを選ばない。明示DOWN、または軸が既知の縦widgetだけを操作する。左右actionも持つWebViewではDOWNだけを使う。途中で固定した縦領域を見失った場合も他の領域へ乗り換えない。日経電子版の縦記事画面を想定した修正であり、紙面ビューアーの縦書き・段組みを検証したものではない。

本文は矩形内の全行ではなく、本文行の選択集合から作る。大きな見出し、複数行で列位置がそろう数表等を除く。画面端という理由だけで短い本文を削除しない。表の前後で本文同士の重なりがなくても、原OCRの連続性と未読行の分類が確かなら表を飛ばして次の本文へ進む。不確実なら停止して確認する。全文・手動範囲・本文だけの復元を用意する。

単語区切りはKuromoji IPADIC 0.9.0のNORMALモードを端末内で使い、POSの根拠がある隣接人名・組織名をまとめる。未知語には任意の保持語辞書を最長一致で優先する。NFC・元surface・Unicode書記素を保ち、論理的な一語が長い場合も表示上は最大12書記素に分ける。辞書準備と解析はUIスレッドで実行しない。手入力した保持語だけを端末設定に保存する。ライセンス・NOTICE・IPADIC通知・CONTRIBUTORSはassetsに同梱し設定画面から閲覧できる。

アプリ切り替え、検知した元アプリの手動操作、未知の上位windowの重なり、回転・サイズ変更、画面ロック、権限解除、OSによる共有停止で停止する。window一覧や実windowが取得できない場合も拒否する。読書欄の操作だけは許容し、package名が同じ通常Activityを例外にしない。読書欄の「自動スクロールを止める」と範囲修正は現在の本文を残して自動だけを停止する。「閉じる」／通知の停止は全読書を終了する。最大50画面。同じ本文や移動不能を繰り返して操作しない。

自動スクロールサービスはcanRetrieveWindowContentを持つが、nodeのtextは読まない。スクロール以外のaction、global action、ジェスチャー注入、キー取得は使わない。Playストア公開の承認を受けたものではなく、デバッグ署名の試用版。サイドロード後の制限付き設定はAndroid公式の案内を開ける。実機での有効化・実操作は未確認。

アイコンは移動・長押し非表示に対応。任意でクイック設定の「ten ボタン」を追加できる。Android 13以降で通知を拒否した場合、通知欄の操作は使えないがアイコンや読書欄の終了操作は使える。

設定画面の終了・履歴からのtask removalでランチャーを停止しない。ランチャーだけSTART_STICKYでOSによる再生成を許可する。画面消灯・ロック中は隠し、SCREEN_ON/USER_PRESENTで再評価する。明示停止・許可解除・強制停止は尊重し、boot receiverはない。取得・読書サービスの同意や本文を再生成しない。メーカー独自の省電力による停止は保証範囲外。

## ネット記事の複数ページ

ブラウザ版のURL取り込みで、同一記事だと確認できる連続ページの本文をまとめる。安定article ID/slug、番号を除去しないcanonicalの一致、同じ見出し、ページ番号の連続性を確認し、候補と転送先にも従来のSSRF検証を行う。合計15秒・5ページ・6MB・20万文字。途中で確認できなければ取得済みだけを残し「途中まで」を案内する。1ページ完結の次記事リンクは追わない。Android重ね表示から汎用ブラウザの次ページボタンを自動タップする機能は含まない。

## 取得とデータ

- 取得はOS同意を受けたセッションのみ。単発は1枚取得後にProjectionを終了する。自動時は同じ共有を保持し、画面間でSurfaceを切り離す。取得同意の再利用・自動復活・ブート開始は行わない。
- 画像と本文は端末内。日本語OCRモデル・単語辞書同梱のAPKは約61MB。画像をファイルへ保存せず、OCR終了後に原寸画像を、読書終了時に縮小画像と本文を解放する。
- 認識中に中止した場合は結果の採用を即座に無効化し、認識処理中の画像は処理終了後に解放する。
- ML KitにはSDK利用状況の計測もある。アプリのINTERNET権限はmerged manifestから除去。実機の通信挙動は未検証なので、端末全体が通信しないという保証とはしない。
- 画面取得禁止の画面には対応しない。本文候補は自動判別なので必要に応じて範囲・文章を直す。縦書き・段組みの読み順は未検証。
- OS停止、画面ロック、重ね表示の取り消しで終了。Android 13以前の取得中の回転は再試行を案内する。OS・省電力設定で常時表示は保証しない。

## ビルドと検証

JDK 17または21、Android SDK 36、Build Tools 35.0.0、Gradle 8.13、AGP 8.12.2。Gradle wrapperには配布ZIPのSHA-256を固定している。

```powershell
.\scripts\build-android.ps1 -SdkRoot C:\path\to\android-sdk -JavaHome C:\path\to\jdk
```

Windowsの日本語パスを避けるため、一時領域へソースをコピーし、GradleキャッシュもASCIIパスに置く。元のフォルダを移動・削除しない。JUnit／Robolectric、Lint、assembleDebug、apksignerの全検証後にpublic/downloads/ten-launcher-debug.apkとSHA-256を保存する。署名鍵とレポートはgit管理外の.ten-cache/に保存。同じ鍵を保持すれば更新できる。

Linux/macOSではJDK・SDKとTEN_DEBUG_KEYSTOREを指定し、androidで ./gradlew testDebugUnitTest lintDebug assembleDebug を実行する。

検証の詳細は docs/android-screen-reading-2026-11-11.md と docs/android-auto-scroll-2026-11-11.md を参照。RobolectricのFrameSource/OcrEngineはテスト用の偽物であり、実機の画面取得やOCRモデル本体の精度を証明しない。自動スクロールのOSイベントテストもJVM上の模擬である。デバッグ署名の試用版として配布し、正式署名・ストア公開・課金は含まない。

0.4の検証・監査記録は docs/vertical-article-reading-2026-11-12.md。固有名詞の辞書自体は実データで検証するが、実機上の初期化時間・メモリ量、日経電子版の実node構造・実認識精度・アイコン維持は未確認である。
