# 読書欄の横幅固定（2026-11-10）

## 変更

- Grid列を`minmax(0, fr)`にし、パネルと表示欄の幅をコンテナ内に固定した。
- 通常は指定文字サイズから一段で収まるよう縮小する。長い表示単位は意味・単語モードの最終段で最大12書記素に分ける。一文字モードは従来どおり。
- 分割は書記素配列のオフセットを進める方式とし、先頭spliceの繰り返しを避ける。原文の非空白文字・順序・絵文字を保持する。空白だけの分割片は表示しない。元の文章の保存・参照内容は変更しない。
- 320pxのヘッダーに収まるよう、集中モード終了のラベルを短縮した。
- WindowsでもビルドできるようURLからファイルパスへの変換を修正し、既存テストのスクリーンショット保存先をPlaywrightの出力先にした。
